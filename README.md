# purgeref

Purge CSV/TSV ref tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/purgeref/

## Install / run

```bash
git clone https://github.com/theworker02/purgeref.git
cd purgeref
node src/cli.js
node --test
```
